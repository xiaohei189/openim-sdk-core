- 对外领域方法放在 `api.go`，底层 RPC 调用收敛在 `server_api.go`，通过私有方法（如 `getUsersInfo`、`updateUserInfo`）被前者复用。
- 跨层数据模型转换集中在 `conversion.go`，使用 `ServerUserToLocalUser` / `LocalUserToPublicUser` 等纯函数，避免在业务逻辑中散落 struct 映射。
- 需要持久化的实体同步一律委托给 `syncer.Syncer`，在 `initSyncer` 中集中注册 Insert/Update/Delete/Callback 四段式钩子，保证幂等与可观测性。
- 对远端 API 的统一调用采用 `api.ExtractField(ctx, api.Xxx.Invoke, req, resp.GetXxx)` 或 `api.Xxx.Execute(ctx, req)` 模式，屏蔽 gRPC 细节。
- 领域事件通过 `common.DispatchUpdateConversation` / `common.DispatchUpdateMessage` 投递到 `conversationEventQueue`，由外部消费方驱动 conversation 与 message 表的级联更新。
