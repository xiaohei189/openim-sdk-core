本模块以 `User` 结构体为核心聚合根，按职责拆分为六个文件：
- `user.go`：定义 `User` 结构体（嵌入 `db_interface.DataBase`、持有 `loginUserID`、`listener`、`conversationEventQueue`、`userCache`），通过 `NewUser` + `SetDataBase/SetLoginUserID/SetListener` 注入依赖；`initSyncer` 注册基于 `pkg/syncer.Syncer[*LocalUser, NoResp, string]` 的增删改回调，将登录用户落库并在昵称/头像变化时派发 conversation/message 更新事件。
- `api.go`：对外暴露的领域方法（`GetSelfUserInfo`、`SetSelfInfo`、`GetUsersInfo`、`GetUserClientConfig`、`UserOnlineStatusChange`），负责组合缓存、好友表、会话表并调用 listener 回调。
- `server_api.go`：封装对远端 user API 的调用（`getUsersInfo`、`updateUserInfo`），统一走 `pkg/api.ExtractField` / `api.UpdateUserInfoEx.Execute`。
- `full_sync.go`：提供 `SyncLoginUserInfo` / `SyncLoginUserInfoWithoutNotice`，拉取远端用户并与本地比对后交给 `userSyncer.Sync` 完成幂等合并。
- `notification.go`：作为消息通知入口，按 `ContentType` 分派到具体处理器（当前仅支持 `UserInfoUpdatedNotification`，对自己触发全量同步）。
- `conversion.go`：纯数据转换函数（`ServerUserToLocalUser`、`LocalUserToPublicUser`），隔离 `sdkws`、`model_struct`、`sdk_struct` 三套协议模型。

依赖方向：本模块只向上依赖 `open_im_sdk_callback`（listener）、`pkg/common`（事件分发）、`pkg/cache`、`pkg/db`、`pkg/syncer`、`pkg/api`、`protocol/*`，不反向依赖上层业务域；`User` 通过接口 `db_interface.DataBase` 解耦数据库实现。
