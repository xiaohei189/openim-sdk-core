- 对外写操作（添加/删除好友、更新备注、加入/移除黑名单）在持久化成功后，统一以 `relationSyncMutex` 串行调用 `IncrSyncFriends` 或 `SyncAllBlackList`，确保并发安全与最终一致。
- 读路径优先使用 `datafetcher.DataFetcher` 构造“本地→DB→服务端”三级回填流程，避免重复查询与手动缓存合并。
- 网络模型到本地模型的转换集中在 `conversion.go`，通过 `ServerXxxToLocalXxx` 命名约定提供单向转换函数，由 `datautil.Batch` 批量调用。
- 所有 HTTP 请求封装在 `server_api.go`，仅做参数拼装与字段提取，业务逻辑不得直接调用 `pkg/api`。
- 同步器在 `initSyncer()` 中一次性配置 Insert/Delete/Update/UUID/Notice/Batch 等钩子，将持久化与 UI 回调（`OnFriendAdded`、`OnFriendDeleted`、`OnFriendInfoChanged`）解耦。
- 通知处理入口 `DoNotification` 内部加 `relationSyncMutex`，并按 `constant.*Notification` 常量分派到对应 Tips 解析与同步分支。
