- 对外方法通过 `api.<Name>.Execute(ctx, &third.XxxReq{...})` 形式调用，请求体直接使用 `github.com/openimsdk/protocol/third` 中的 proto 结构体，避免重复定义。
- 需要跨 goroutine 保护的共享状态（如 `File.uploading` map、`Third.logUploadLock`）采用显式的 `sync.Mutex`/`sync.Locker` 字段配合 `lockHash/unlockHash` 等辅助方法管理生命周期。
- 大文件 I/O 通过组合 `io.Reader` 装饰器链实现：`NewMd5Reader(io.LimitReader(...))` 叠加 MD5 计算，再用 `NewProgressReader` 注入进度回调，职责单一且可复用。
- 平台相关实现使用 Go build tag 分离（`//go:build !js` 与 `//go:build js && wasm`），公共接口集中在同名文件中，由构建系统自动选择。
