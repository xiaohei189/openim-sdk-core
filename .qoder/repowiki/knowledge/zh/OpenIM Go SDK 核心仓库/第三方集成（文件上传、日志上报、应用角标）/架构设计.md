模块按职责拆分为顶层 `third` 包与子包 `file`：
- `third.go` 定义 `Third` 结构体，持有 platform/loginUserID/appFramework/logFilePath 等上下文，并通过注入的 `*file.File` 完成文件操作；`NewThird` 是唯一构造入口。
- `api.go` 将 `UpdateFcmToken`、`SetAppBadge`、`UploadLogs`、`Log` 等对外方法直接委托给 `pkg/api` 下的 RPC 调用（如 `api.FcmUpdateToken.Execute`），仅做参数拼装。
- `log.go` 实现日志采集：根据 `line` 参数选择全部或最近 N 行日志，使用 `zipFiles` 压缩后通过 `fileUploader.UploadFile` 上传，再调用 `api.UploadLogs` 通知服务端；`progressConvert` 把 `UploadFileCallback` 适配为 `Progress.OnProgress`。
- `file/` 子包封装分片上传核心：`upload.go` 中的 `File` 负责计算 partSize/partNum、MD5 校验、向服务端发起 `ObjectInitiateMultipartUpload`/`ObjectAuthSign`/`ObjectCompleteMultipartUpload` 并 PUT 各分片；`bitmap.go` 用位图记录已上传分片，`md5.go` 提供流式 MD5 读取器，`progress.go` 提供 `ProgressReader` 回调进度，`cb.go` 定义 `UploadFileCallback` 接口。
- 平台差异通过构建标签拆分：`file_default.go`（`!js`）与 `file_js.go`（`js && wasm`）分别实现 `Open` 函数，使同一 API 在 Go/WASM 环境均可工作。
依赖方向：`third` → `file` → `pkg/api` + `pkg/db`；`file` 不反向依赖 `third`，保持可复用性。
