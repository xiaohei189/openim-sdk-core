- 每个 internal 领域目录遵循 api.go / server_api.go / conversion.go / incremental_sync.go / notification.go 的文件职责划分
- 对外 API 一律通过 `call(callback, operationID, fn, args...)` 包装，以 JSON 字符串经 Base/SendMsgCallBack 异步返回，禁止直接阻塞调用
- 领域间不互相 import，仅通过 pkg/ 下的 db/cache/syncer/converter 等基础设施包共享数据模型与工具
- 错误码集中定义在 pkg/sdkerrs/code.go，领域层使用预定义常量而非裸 error
