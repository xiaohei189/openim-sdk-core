本模块是 `wasm` 子树唯一的可执行入口，仅包含 `main.go`、`Makefile` 和运行时依赖 `static/wasm_exec.js`。
- 编译约束：通过 `//go:build js && wasm` + `+build js,wasm` 双标签限定仅在 GOOS=js/GOARCH=wasm 下参与构建。
- 进程模型：`main()` 中先 defer recover 捕获 panic，打印 runtime 环境后调用 `registerFunc()` 完成所有全局函数注册，最后 `<-make(chan bool)` 阻塞主 goroutine 使 WASM 实例存活。
- 接口边界：通过 `js.Global().Set(name, js.FuncOf(...))` 把内部 `wasm_wrapper` 包下的各 Wrapper（Common/InitLogin/ConMsg/Group/User/Friend/Third）暴露为浏览器可直接调用的驼峰方法名（如 `initSDK`、`login`、`createTextMessage`、`getJoinedGroupList`、`addFriend`、`uploadFile` 等），形成 Go→JS 的单向桥接面。
- 依赖方向：本模块只依赖上层 `github.com/openimsdk/openim-sdk-core/v3/wasm/wasm_wrapper`，不直接引用任何业务域实现，起到“路由注册表”的作用。
- 构建产物：`Makefile` 提供 `wasm`（输出 `openIM.wasm`）、`build`（同时拷贝 GOROOT 的 `wasm_exec.js` 并启动本地 HTTP 服务在 :9999 托管静态资源）两个目标。
