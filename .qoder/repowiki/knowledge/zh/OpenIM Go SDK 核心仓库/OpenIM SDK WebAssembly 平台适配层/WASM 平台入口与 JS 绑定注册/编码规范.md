- 每个对外暴露的 JS 方法都通过 `js.Global().Set("methodName", js.FuncOf(wrapper.Method))` 的形式注册，保持名称与内部 Wrapper 方法一一对应。
- Wrapper 按业务域拆分（InitLogin/ConMsg/Group/User/Friend/Third），每个域由独立的 `NewWrapperXxx(globalFuc)` 构造器创建，再统一在 `registerFunc` 中集中注册。
- 入口 `main` 始终使用 defer recover 包裹 panic 恢复，并通过无限 channel 阻塞主协程，确保 WASM 实例不被 GC 回收。
