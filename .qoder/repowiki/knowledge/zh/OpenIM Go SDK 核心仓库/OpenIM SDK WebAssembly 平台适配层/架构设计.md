本模块是 OpenIM SDK 的 WebAssembly 平台适配层，按以下层次组织跨子模块协作：
- 入口层（cmd_entry）：`main.go` 仅做 `js.Global().Set(...)` 注册，把 `wasm_wrapper` 下各 Wrapper 实例挂载为全局函数，作为 Go↔JS 的唯一边界。
- 桥接层（wasm_wrapper + event_listener）：每个业务域（conversation_msg/group/friend/user/third/signaling/init_login）对应一个 Wrapper，负责解析 js.Value 参数、调用 open_im_sdk 接口，并通过 `event_listener` 把 SDK 内部回调统一转发给上层宿主；`event_listener` 同时提供 Caller/Promise 到 Go 回调的双向转换。
- 执行与序列化（exec）：`Exec()` 是 Go 主动调用 JS Promise 的统一通道，所有需要等待 JS 异步结果的场景都走此方法，约定以 `CallbackData{ErrCode,ErrMsg,Data}` 结构返回错误码与数据。
- 持久化（indexdb_persistence）：基于 exec 桥接 IndexedDB，按表模型（user/group/conversation/chat_log/black_model/upload 等）提供 SQL 级访问，由 `table_master` 统一管理建表与版本同步。
- 构建产物：`cmd/Makefile` 使用 `GOOS=js GOARCH=wasm` 编译，依赖 `cmd/static/wasm_exec.js` 在宿主环境加载。
