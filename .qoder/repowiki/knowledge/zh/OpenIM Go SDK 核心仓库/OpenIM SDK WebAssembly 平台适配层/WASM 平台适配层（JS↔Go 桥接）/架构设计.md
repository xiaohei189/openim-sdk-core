本模块是 `open_im_sdk` 在 `js/wasm` 构建标签下的适配层，按业务域拆分为多个 `Wrapper*` 结构体文件：`wasm_init_login.go`（初始化、登录、网络状态）、`wasm_conversation_msg.go`（会话与消息 CRUD）、`wasm_friend.go`（好友关系）、`wasm_group.go`（群组管理）、`wasm_user.go`（用户信息/在线状态）、`wasm_signaling.go`（信令）、`wasm_third.go`（第三方集成）。每个 Wrapper 嵌入公共的 `WrapperCommon`，后者持有从 JS 注册的 `commonEventFunc` 回调句柄，用于把底层 `event_listener` 推送的事件反向调用回 JS。所有对外方法签名统一为 `func(_ js.Value, args []js.Value) interface{}`，内部通过 `event_listener.NewCaller(open_im_sdk.Xxx, callback, &args)` 包装成同步或异步调用（`SyncCall` / `AsyncCallWithCallback` / `AsyncCallWithOutCallback`），由 `utils.FirstLower(utils.GetSelfFuncName())` 自动推导函数名作为回调标识。依赖方向单向：本模块 → `open_im_sdk` + `pkg/utils` + `wasm/event_listener`，不反向依赖上层 JS 代码。
