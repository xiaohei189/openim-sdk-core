- 所有对外暴露的 JS 函数均在 `cmd/main.go` 中集中 `js.Global().Set(name, js.FuncOf(...))` 注册，禁止在其他位置直接操作 js.Global()。
- Go 主动调用 JS 时统一走 `exec.Exec()`，通过 Promise then/catch 通道并以 `CallbackData` 结构体承载 errCode/errMsg/data。
- 业务域按 conversation_msg/group/friend/user/third/signaling/init_login 拆分独立 Wrapper 文件，每个 Wrapper 持有公共 `globalFuc` 用于事件回调。
- IndexDB 表模型以单文件 struct 定义（如 user_model.go、group_model.go），并由 `table_master.go` 统一注册建表逻辑。
