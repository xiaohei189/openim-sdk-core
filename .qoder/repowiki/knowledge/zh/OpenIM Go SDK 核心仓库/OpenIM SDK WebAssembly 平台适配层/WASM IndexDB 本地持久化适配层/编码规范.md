- 每个源文件顶部附带 `//go:build js && wasm` 与 `+build js,wasm` 双行构建标签，限定仅 WASM 目标参与编译。
- 读取型方法遵循固定模式：`exec.Exec()` → 断言返回值类型为 `string` → 调用 `utils.JsonStringToStruct` 反序列化为 `model_struct.*` → 返回指针切片并取地址。
- 写入型方法统一将入参经 `utils.StructToJsonString` 序列化后作为 `exec.Exec` 参数传递，错误直接透传。
- 更新操作在调用 `exec.Exec` 前先构造 `temp_struct` 下的轻量结构体进行字段拷贝，避免触发全量 select(*)。
- 主键校验采用前置判断空值并返回 `exec.PrimaryKeyNull` 的方式，而非交由底层处理。
- 业务实体按领域拆分到独立文件（如 conversation_model.go、group_model.go、friend_model.go），并在 `IndexDB` 中以嵌入或指针组合方式聚合。
