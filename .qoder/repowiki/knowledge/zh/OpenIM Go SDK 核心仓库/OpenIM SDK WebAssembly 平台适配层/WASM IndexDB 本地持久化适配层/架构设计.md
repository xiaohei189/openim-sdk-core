模块以 `init.go` 中的聚合结构体 `IndexDB` 作为对外入口，组合了 `LocalUsers`、`LocalConversations`、`*LocalChatLogs`、`LocalConversationUnreadMessages`、`LocalGroups`、`LocalGroupMember`、`*Black`、`*Friend` 等按业务域划分的子存储接口（conversation_msg、group、interaction、relation、user），并通过 `InitDB`/`Close` 调用 `wasm/exec` 初始化/关闭底层 IndexedDB。

- 跨语言边界：所有方法统一通过 `exec.Exec(args...)` 调用 JS 侧实现的 SQL 生成与执行；返回值为 `interface{}`，读取路径一律先断言 `string` 再经 `utils.JsonStringToStruct` 反序列化为 `pkg/db/model_struct` 下的模型，写入路径则用 `utils.StructToJsonString` 序列化后传入。
- 字段映射隔离：`temp_struct/struct.go` 定义仅用于 JSON 传输的驼峰 tag 结构体，与 `model_struct` 的 snake_case DB 字段解耦，更新类方法在调用前做显式拷贝转换，避免 GORM select(*) 带来的额外开销。
- 版本同步：`version_sync.go` 提供独立的 `LocalVersionSync` 表，配合 `app_version.go` 的 `LocalAppSDKVersion` 管理 SDK 本地 schema 版本。
- 构建约束：每个文件顶部使用 `//go:build js && wasm` 标签，确保仅在 WASM 目标下编译。
