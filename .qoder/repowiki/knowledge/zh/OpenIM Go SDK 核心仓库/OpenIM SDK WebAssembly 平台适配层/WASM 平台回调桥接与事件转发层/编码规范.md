- 所有回调方法统一采用 `i.CallbackWriter.SetEvent(utils.GetSelfFuncName()).SetData(...).SendMessage()` 链式调用，event 名由反射自动取当前方法名。
- 回调结构体普遍嵌入 `CallbackWriter` 字段，并通过 `NewXxxCallback(callback *js.Value)` 构造函数完成初始化，保持对外 API 一致性。
- 需要同时走 Promise 与全局事件的回调（如 `UploadFileCallback`、`SendMessageCallback`）会额外保存一个 `globalEvent CallbackWriter`，分别用于单次返回值与进度/中间状态推送。
- `caller.go` 中 JS→Go 参数转换一律用 `switch typeFuncName.In(i).Kind()` 显式分支处理基本类型，遇到不支持类型直接 panic 而非静默跳过。
