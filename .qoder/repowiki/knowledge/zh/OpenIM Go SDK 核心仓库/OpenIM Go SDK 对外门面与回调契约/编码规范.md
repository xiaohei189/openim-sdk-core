- 对外函数签名固定为 `(callback open_im_sdk_callback.Base, operationID string, args...)`，由 `call` 包装后在 goroutine 中执行并通过 `OnSuccess/OnError` 异步返回。
- JSON 入参约定：当目标函数参数类型为 struct/slice/map/ptr 且调用方传入 string 时，由反射自动 `json.Unmarshal` 反序列化；数值型参数支持 int↔uint↔float 互转。
- 监听器回调采用 `empty*Listener` 空实现 + 上层覆写模式，未实现的方法默认仅打 ZWarn 日志而不抛错。
- 错误处理统一走 `errs.Unwrap(err).(errs.CodeError)` 取 code/msg/detail，未知错误降级为 `sdkerrs.UnknownCode`。
