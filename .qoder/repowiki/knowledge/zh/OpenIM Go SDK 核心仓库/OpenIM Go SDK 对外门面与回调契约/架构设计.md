模块由两个子包构成：
- `open_im_sdk/`：SDK 对外暴露的函数门面（init_login、user、group、relation、conversation_msg、third、online、listener 等按业务域拆分），所有对外函数统一通过 `caller.go` 中的 `call` / `messageCall` / `syncCall` 三个反射调度器执行——自动注入 `context.Context`、把 JSON 字符串参数反序列化为目标结构体、捕获 panic、记录耗时日志，并将返回值或 error 经 `open_im_sdk_callback.Base.OnSuccess/OnError` 回传；同时提供 `empty*Listener` 空实现（`em.go`）供上层按需覆盖。
- `open_im_sdk_callback/`：纯接口定义包，声明 `Base`、`SendMsgCallBack`、`OnConnListener`、`OnGroupListener`、`OnFriendshipListener`、`OnConversationListener`、`OnAdvancedMsgListener`、`OnUserListener`、`OnCustomBusinessListener`、`OnMessageKvInfoListener`、`OnSignalingListener`、`UploadFileCallback`、`UploadLogProgress` 等回调契约；`callback_go_sdk.go` 提供 `OnFriendshipListenerSdk` 适配器，把内部 `model_struct.LocalFriendRequest` 等强类型事件转为 JSON 字符串再转发给上层实现的 `OnFriendshipListener`。
依赖方向单向：`open_im_sdk` → `open_im_sdk_callback` + `pkg/*`，回调包不反向依赖任何业务实现。
