本模块为 internal 按业务域划分的 group 子域，围绕 `Group` 结构体组织，按职责拆分为多个文件：
- `group.go`：定义 `Group` 结构体（持有 db、syncer、cache、filter、listener 等依赖），通过 `NewGroup` 构造并初始化两个 `syncer.Syncer`——`groupSyncer`（LocalGroup，以 GroupID 为 UUID）和 `groupMemberSyncer`（LocalGroupMember，以 [GroupID,UserID] 为复合 UUID），同时注册 Insert/Delete/Update/BatchInsert/Notice 钩子，在 Notice 阶段回调上层 listener 并触发 conversation/message 的局部刷新。
- `api.go`：面向 SDK 上层的公开 API（CreateGroup/JoinGroup/QuitGroup/DismissGroup/ChangeGroupMute/KickGroupMember/SetGroupInfo/GetJoinedGroupList/GetGroupMemberList/SearchGroups 等），统一在写操作后加 `groupSyncMutex` 再调用 `IncrSyncJoinGroup` / `IncrSyncGroupAndMember` 驱动增量同步；读路径大量复用 `pkg/datafetcher.DataFetcher` 做“本地→数据库→服务器”三级缓存回填。
- `server_api.go`：纯网络适配层，把协议请求组装为 `pkg/api.*.Invoke/Execute/Page/ExtractField` 调用，屏蔽底层 HTTP/gRPC 细节。
- `incremental_sync.go`：核心同步编排，`IncrSyncJoinGroup` 使用 `VersionSynchronizer[LocalGroup]` 拉取用户已加入群的增量；`IncrSyncGroupAndMember` 批量聚合多群成员增量请求（受 `MaxSyncPullNumber` 限制），对每个群用 `VersionSynchronizer[LocalGroupMember]` 执行增量或回退 FullSync，并通过 `ExtraDataProcessor` 联动更新群信息。
- `full_sync.go`：暴露 `GetServerJoinGroup` / `SyncAllJoinedGroupsAndMembers` 作为全量同步入口。
- `notification.go`：消息推送入口 `DoNotification`，按 `constant.Group*Notification` 类型分发，对涉及自身加入状态变化的事件走 `IncrSyncJoinGroup`，其余走 `onlineSyncGroupAndMember` 直接应用增量到本地。
- `conversion.go` / `filter.go` / `cache.go`：辅助转换函数（Server↔Local）、去重过滤（NotificationFilter 带 TTL）、内存缓存封装。

依赖方向：`api.go` → `server_api.go` → `pkg/api`；所有写路径经 `groupSyncMutex` 串行化，再通过 `syncer` 与 `datafetcher` 落库；不直接依赖 `open_im_sdk_callback`，而是通过注入的 `listener` 回调向上层 SDK 异步返回结果，符合作者“open_im_sdk 通过 callback 模式向上层平台 SDK 异步返回结果”的约定。
