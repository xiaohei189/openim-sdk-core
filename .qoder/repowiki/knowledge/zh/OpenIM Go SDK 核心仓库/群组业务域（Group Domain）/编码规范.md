- 写操作（创建/加入/踢人/改信息等）先调 server_api 完成远端写入，随后加 `groupSyncMutex` 锁，再调用 `IncrSyncJoinGroup` 或 `IncrSyncGroupAndMember` 保证本地与服务器一致。
- 读路径统一通过 `datafetcher.NewDataFetcher(db, tableName, entityID, keyFunc, batchInsert, localQuery, serverQuery)` 构建三级缓存（内存→DB→Server），并按需选择 `FetchWithPagination` / `FetchMissingAndCombineLocal` / `FetchMissingAndFillLocal`。
- 同步逻辑通过 `syncer.WithXxx` 选项式配置 `Syncer`，将插入/删除/更新/批处理/分页请求/响应转换/路由/限流等横切关注点声明式注入，而非手写循环。
- 增量同步使用 `VersionSynchronizer`，通过 `Version`/`Delete`/`Insert`/`Update`/`Full`/`FullID`/`IDOrderChanged` 等回调描述差异，并在 `ExtraDataProcessor` 中联动更新关联实体（如成员增量时顺带更新群信息）。
- 通知分发采用 `switch msg.ContentType` 按常量 ID 分支，解析 Tips 后根据是否涉及自身加入状态决定走 `IncrSyncJoinGroup` 还是 `onlineSyncGroupAndMember`。
- 对外错误统一使用 `sdkerrs.Err*` 与 `errs.Wrap` 包装，空结果场景返回空切片而非 nil，避免上层判空歧义。
