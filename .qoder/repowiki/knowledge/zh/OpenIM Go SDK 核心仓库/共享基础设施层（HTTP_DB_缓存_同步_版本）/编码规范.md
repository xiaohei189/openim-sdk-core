- API 路由采用 `newApi[Req,Resp]("/path")` 泛型构造 + 包级变量集中注册，调用方只引用变量并调用 `Invoke/Execute`。
- 数据库访问通过 `db_interface` 中细粒度领域接口（GroupModel/MessageModel 等）组合成 `DataBase` 接口，实现文件按实体拆分且统一加 `//go:build !js` 标签。
- 可配置对象使用 Option 函数模式（`WithInsert/WithUpdate/...`），配合 `New2[T,RESP,V](opts...)` 构造，避免过多构造函数参数。
- 通用组件优先使用 Go 1.18+ 泛型（`Cache[K,V]`、`Api[Req,Resp]`、`Syncer[T,RESP,V]`、`ExtractField[A,B,C]`、`Page[Req,Resp,Elem]`）。
- 错误处理统一使用 `github.com/openimsdk/tools/errs` 的 `Wrap/WrapMsg/Unwrap` 系列进行包装与解包。
