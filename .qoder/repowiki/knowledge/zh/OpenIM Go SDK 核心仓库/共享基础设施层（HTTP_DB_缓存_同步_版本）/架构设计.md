本模块按横切能力划分子包，被 `internal/` 各业务域依赖：
- `api/fn.go` 通过泛型 `Api[Req,Resp]` + 全局变量集中声明所有 `/user /friend /group /msg /conversation /auth /third /object` 路由，统一委托 `network.ApiPost` 发起请求；`Page[...]` 封装分页拉取。
- `db/` 以 `db_interface/databse.go` 定义 `DataBase` 接口（聚合 GroupModel/MessageModel/ConversationModel/UserModel/FriendModel/S3Model/SendingMessagesModel/VersionSyncModel/AppSDKVersion/TableMaster），由 `db_init.go` 基于 GORM+SQLite 实现，并通过 `//go:build !js` 标签在 JS 平台排除；模型集中在 `model_struct/data_model_struct.go`，每个实体一个文件（如 `chat_log_model.go`、`conversation_model.go`）。
- `cache/cache.go` 提供泛型 `Cache[K,V]` 内存缓存，`conversation_seq_cache.go`、`user_cache.go` 是具体实例。
- `syncer/syncer.go` 用泛型 `Syncer[T,RESP,V]` + Option 模式封装增删改对比逻辑，配合 `version_synchronizer.go` 做增量同步。
- `converter/` 将协议结构体转换为本地模型，`ccontext/` 承载上下文传递，`sdk_params_callback/` 和 `server_api_params/` 分别存放 SDK 回调与服务器 API 的中间结构体。
- `version/` 通过 `base.go` 中的 git 占位符 + `-ldflags` 注入机制输出语义版本，供 DB 迁移比较使用。
依赖方向：`api → network`，`syncer → api/page/network`，`db` 仅依赖 `gorm/sqlite` 与本包 `constant/version`，其他包不反向依赖 `db`。
